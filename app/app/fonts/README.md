# Inter

Inter normal variable font, weights 300–800, served locally to avoid a render-blocking external stylesheet request.

These WOFF2 subsets come from the Google Fonts Inter v20 CSS response for
`https://fonts.googleapis.com/css2?family=Inter:wght@300..800&display=swap`
(retrieved 2026-11-08). Subset names and Unicode ranges are preserved in `inter.css`.
Vite fingerprints the font files and bundles the declarations into the application CSS.
`font-display: swap` keeps text readable while fonts download.
